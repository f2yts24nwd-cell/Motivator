# Markenassets

`itmx-logo.svg` ist aktuell ein **Platzhalter**. Ersetze die Datei durch das offizielle
itmX-Logo aus dem Styleguide auf itmx.de (am besten die helle/weiße Variante, da es auf
dunklem Grund steht). Das Spiel lädt die Datei automatisch – Code-Änderungen sind nicht nötig.
Wichtig bei SVG: `width`- und `height`-Attribute im `<svg>`-Tag setzen.
