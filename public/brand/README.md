# Markenassets

`itmx-logo.png` ist das offizielle itmX-Symbol (grüne Kachel mit weißem X), bereitgestellt vom Auftraggeber.
Es wird für Schild, Teppich, Zertifikat und Automaten-Bildschirm verwendet. Der 3D-Kopf im Spiel ist aus
seinem Umriss modelliert (siehe `LOGO_TILE`/`LOGO_X` in `src/games/whack/targets.js`).
